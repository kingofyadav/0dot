# Security Policy

0dot.in is a private repository; this policy covers responsible disclosure
for anyone with repository access.

## Reporting a vulnerability

This is a private repository, so a regular [GitHub issue](../../issues/new)
is only visible to collaborators and is fine for reporting a vulnerability.

Include what you found, steps to reproduce, and the affected area (web,
mobile, API) if known. We'll acknowledge reports and follow up with a fix
timeline.

## Supported versions

Only the latest deployment on `main` (https://0dot.in) is supported.
